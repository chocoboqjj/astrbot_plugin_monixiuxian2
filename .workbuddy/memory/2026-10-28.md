## v3.3.12 - 丹药配方 / 储物戒 面板卡片化（对标商店布局）
用户：「丹药配方和储物戒的图也可以像商店那样优化一下布局」。

### 做法（照抄商店 _parse_shop_items/_render_shop 模式）
- `_parse_recipes` / `_is_recipe` / `_render_recipe`：锚点 = 配方头行 `【名】(ID:n)`；卡片含 #ID 徽标、
  成功率右对齐、需求境界胶囊、破境丹「突破目标」徽标（✅可炼 / 🔒未达境界）、材料按 `[,，、]` 拆项加粗。
  **单列**卡片（材料串长，双列会挤压）。
- `_parse_storage` / `_is_storage` / `_render_storage`：戒名+品级徽标+**容量进度条**（复用 `_progress`）
  + 按分类的双列物品格（带 ×数量）；`【存储物品】空` → `（空）`。
- CSS 新增 `.r-*`（配方）`.st-*`（储物戒）两组类，挂共享 `_CSS` ⇒ 双主题自动生效。
- 分发顺序：商店 ① → 配方 ② → 储物戒 ③ → 通用。

### 踩坑
- **⚠️「储物戒列表」（/更换储物戒 候选）也含「储物戒」**，但字段是「容量：N格 | 需求：境界」且多枚戒子，
  按主面板渲染会错位 ⇒ `_is_storage` 必须用 **「的储物戒」** 精确排除，不能只判「储物戒」。
- **⚠️ 断言面板类型必须匹配 `class="xxx"` 属性，不能匹配类名子串**：`.r-list`、`.st-grid` 这类类名
  同样存在于 `<style>` 里 ⇒ `"r-list" in html` 恒为真，测试会假阳性。角色卡是 `class="dname gold-t"`，
  精确写 `class="dname"` 也会落空。正确姿势：`'class="r-list"' in html`。
- 戒名括号有全角/半角两种（主面板 `（地品）` vs 升级列表 `(60格)`）⇒ 正则用 `[（(]…[）)]`。
