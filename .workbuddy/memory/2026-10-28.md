### 踩坑（本轮新增）
- **bash `grep "a\|b"` 在本环境返回空**（不是文件没内容）⇒ 用 `grep -E "a|b"` 或专用 Grep 工具。曾据此误判 main.py 没有 render 代码。
- 测试 mock astrbot 时，项目有 `from astrbot.api.all import *` ⇒ 桩模块**必须设 `__all__`**，否则 `TypeError: '_Perm' object is not iterable`；装饰器桩须**返回原函数**，否则类方法被替换成桩对象。
- 断言「requirements 无 Pillow」时，注释里的说明文字含 Pillow 字样 ⇒ 只比对**非 # 注释行**。
